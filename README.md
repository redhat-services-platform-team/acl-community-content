# ACL Community Content

Public Ansible Content Library (ACL) corpus for community contributions.

This repository is maintained by the [Red Hat Services Platform Team](https://github.com/redhat-services-platform-team).
Playbooks and roles must meet the same engineering bar as
[acl-ready-to-use-content](https://github.com/redhat-services-platform-team/acl-ready-to-use-content):
[GPA](https://redhat-cop.github.io/automation-good-practices/), ansible-lint
`production` profile, and testing on Ansible Automation Platform 2.6+.

Bootstrap of layout, contribution rules, and CI is in progress.
